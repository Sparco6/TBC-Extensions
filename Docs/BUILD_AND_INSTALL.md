# Build and install — existing TBCExtensions project

Build the existing `TBC-Extensions/TBC-Extensions` CMake project, not AoREngine. Requirements: Windows, CMake ≥3.25, Visual Studio C++ x86 toolchain, C++17, `-A Win32`, bundled sibling `../AoREngine-main/deps/minhook` (MinHook is the only linked hook dependency). `TBCExtensions/CMakeLists.txt` generates `TBCExtensions/include/PatchConfig.hpp` from `cmake/PatchConfig.hpp.in`; inspect `UNSAFE_LEGACY_PORT=OFF` in cache/output. `CUSTOM_DBC` option defaults OFF for **legacy stock DBC patch**, but DLL-owned `NativeDBC::Request` is compiled independently. Do not turn unsafe options on to make a test work. Typical commands from `TBC-Extensions/TBC-Extensions`:

```powershell
cmake -S . -B build-x86-vs18 -G "Visual Studio 18 2026" -A Win32 -DUNSAFE_LEGACY_PORT=OFF
cmake --build build-x86-vs18 --config Release --target TBCExtensions
```

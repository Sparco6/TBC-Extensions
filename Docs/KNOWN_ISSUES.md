- **Current research blocker:** both controlled requests hit `0x00457FC0`, but no `0x00455EF0`/`0x005B1BA0` call is correlated to either. Global totals changed; deferred/alternate/cache/unrelated causes are **UNKNOWN**. The owner-tested v2 trace gave the same raw pointer `0x27E8AC08` for both sequential tests and zero deep equality candidates. Do not use that address as unique per-texture identity; Clear releases the retained refcounted resource and an allocation may be reused.
- **BGRA8 stock output incorrect:** fresh-client original encoding-3 BGRA8 displays a distinct corrupted horizontal/pixel pattern. The offline DXT5 copy displays correct quadrants. This supersedes the earlier stale-preview/blank classification, but is not a correct stock BGRA8 PASS. No replacement or descriptor patch is approved.

- **Legacy zero placeholders:** `UNSAFE_LEGACY_PORT` must remain OFF. Relevant `TODO_TBC`/`0x000000` categories in `TBCExtensions/src/`: Main bootstrap/global writes; `CDBCMgr/CDBCMgr.cpp` stock registration patch; `Client/SFile.cpp` CloseFile; map/model and rendering guards; packet and player/tooltip/spell utilities; numerous `Client/CustomLua.cpp` spell/talent/item/action/object manager/locale/FPS stubs.

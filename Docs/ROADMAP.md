# Roadmap — gated, not implemented by reference source

Phase 0: existing loader, fingerprinted safe Lua/native research foundation (**partially runtime verified**). Phase 1: selective BLP compatibility; the independent parser and offline controlled conversion exist, but runtime ownership and cache integration do not. Fresh-client original BGRA8 is visibly corrupted while offline DXT5 is correct; both hit the request boundary, but no deeper controlled correlation exists. First identify a distinguishing resource/path field and the post-parse format divergence, then qualify any new observation; real byte-identical 3.3.5a BLP assets remain deferred. Preserve stock-compatible source paths.

Only after Phase 1: FileDataID/path resolver plus retail file index; modern M2 parser; SKIN parser; isolated D3D9 model proof (not stock player); bone-palette and animation/external `.anim`/`.bone`/`.physics`; attachments; particles/ribbons; creature display integration; item/equipment; character; spell/world visuals. These phases are conceptual and require separate TBC address/ABI and memory-lifetime qualification. The DLL-owned AoR creature WDBC schema is **not** a completed creature-display phase. A first retail-model test should use an isolated model browser/proof, not live player pipeline.

AoREngine source at sibling `../AoREngine-main` targets 3.3.5a/12340. **REUSE** independent format readers/tests where compatible; **PORTABLE-ADAPT** BLP/M2/SKIN/animation algorithms, external asset handling and rendering lessons; **TBC-HOOK-REQUIRED** FileDataID, RetailFile, D3D9/client resource APIs, creature/item/character/spell paths; **RISKY** palette overflow, 32-bit indices, texture combine/blend, ribbons/particles, source lifetime and cache, stock player integration; **NOT CURRENTLY NEEDED** broad retail world/spell visual integration. AoREngine's MD21/MD20 conversion, skin splitting, animation lookup/alias chasing, shader/blend/ribbon fixes are design lessons only, not TBCExtensions capabilities. Its WotLK hooks and addresses cannot be copied to 8606. Reference: `Docs/AORENGINE_TBC_PORT_AUDIT.md`, `../AoREngine-main/src/` and `../AoREngine-main/tools/`.
